Дипломная работа: Java-разработчик

Описание проекта
Учебный дипломный проект по профессии Java-разработчик.  
Приложение представляет собой аналог Avito: пользователи могут регистрироваться, авторизовываться, публиковать объявления, оставлять комментарии и загружать изображения.  
Фронтенд предоставлен школой и запускается в Docker, бэкенд реализован мной.

Запуск проекта
1. Запуск фронтенда
   docker run -p 3000:3000 --rm ghcr.io/bizinmitya/front-react-avito:v1.21

2. Запуск PostgreSQL
   docker run --name postgres \
   -e POSTGRES_DB=app \
   -e POSTGRES_USER=app \
   -e POSTGRES_PASSWORD=pass \
   -p 5432:5432 \
   -d postgres:15

3. Запуск backend
   ./mvnw spring-boot:run

4. Доступы
- Swagger UI: http://localhost:8080/swagger-ui.html
- OpenAPI JSON: http://localhost:8080/v3/api-docs
